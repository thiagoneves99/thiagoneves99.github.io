Política de Privacidade

Última atualização: 10 de outubro de 2026

Esta política vale para o aplicativo "Deus e Maior Publicador", ferramenta interna do canal I.A Coral Deus é Maior.

Quem usa

Somente o proprietário do canal, com a própria conta Google. O aplicativo não é distribuído a outras pessoas.

Dados acessados

Com a autorização do proprietário (escopo do YouTube), o aplicativo acessa apenas o próprio canal para enviar vídeos, definir miniaturas, gerenciar playlists, alterar privacidade/agendamento e listar os vídeos do canal. Não acessa dados de outros usuários, e não coleta, vende ou compartilha dados pessoais.

Armazenamento

O token de acesso fica somente no computador do proprietário, em arquivo local protegido. Nenhum dado é enviado a servidores de terceiros além das APIs do Google/YouTube.

Revogação

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

Uso dos Serviços de API do YouTube

O aplicativo usa os Serviços de API do YouTube (YouTube Data API e YouTube Analytics API) para: enviar e atualizar vídeos do próprio canal, definir miniaturas e playlists, ler métricas do canal e dos vídeos, e ler, responder e moderar comentários nos vídeos do canal.

Exclusão de dados

O aplicativo não mantém banco de dados. O único dado guardado é o token de autorização, no computador do proprietário; ele é apagado ao revogar o acesso em myaccount.google.com/permissions ou ao remover o arquivo local. Pedidos de exclusão ou dúvidas: thiagoneves.estacio@gmail.com (resposta em até 7 dias). Dados obtidos da API não são guardados por mais de 30 dias.

Google e YouTube

Este aplicativo usa os Serviços de API do YouTube. Ao usá-lo, aplicam-se os Termos de Serviço do YouTube e a Política de Privacidade do Google.

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
